# build-tabs — 리서치 문서 3편을 탭 하나로 합치는 빌드 스크립트

`docs/research/`의 독립 HTML 문서들을 탭 UI 하나로 병합합니다.

```bash
cd <문서들이 있는 디렉터리>
python3 build_tabs.py     # → capture-research-tabs.html
```

## 왜 스크립트가 필요한가

세 문서를 그냥 이어 붙이면 깨집니다. 셋 다 `.tier` · `.page` · `.stat` 같은
클래스를 **서로 다른 의미로** 쓰기 때문입니다. 예를 들어 `.tier`는
「경쟁 분석」에서는 계층 표의 한 행이고, 「분류 체계」에서는 사다리 카드입니다.

그래서 이 스크립트는

1. 각 문서의 CSS 규칙을 그 문서의 패널 아래로 **스코프**합니다 (`.tier` → `#p2 .tier`)
2. `:root` 토큰만 하나로 **병합**합니다 — 먼저 나온 값이 이깁니다
3. `--measure` · `--wide`(본문 폭)는 문서마다 다르므로 **패널별로 유지**합니다.
   전역화하면 서로 덮어써서 레이아웃이 바뀝니다
4. light / dark / `[data-theme]` 세 블록을 각각 하나로 정리합니다

## 탭 동작

- 해시(`#01` `#02` `#03`)로 딥링크. **패널 id와 일부러 다르게 두었습니다** —
  같으면 브라우저가 그 요소까지 스크롤해서 머리말이 잘린 채 열립니다
- 마지막으로 본 탭을 `localStorage`에 기억 (사생활 보호 모드에서도 안전하게 실패)
- 방향키 · Home · End 로 탭 이동, `role="tablist"` / `aria-selected` 적용

## 문서를 추가하려면

`DOCS` 배열에 `(패널id, 파일명, 번호, 짧은이름, 부제)` 한 줄을 더합니다.
패널 id는 `p4`처럼 겹치지 않게 두면 됩니다.
