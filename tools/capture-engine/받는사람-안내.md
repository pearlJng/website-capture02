# 웹사이트 스냅샷 — 설치해서 쓰기 (맥)

## 처음 한 번
1. 터미널을 엽니다 (Spotlight 에서 "터미널" 검색).
2. 아래 한 줄을 붙여 넣고 Enter 를 누릅니다. 이미 설치돼 있어도 괜찮습니다(갱신만 합니다).

```
bash <(curl -fsSL https://raw.githubusercontent.com/pearlJng/website-capture02/claude/website-snapshot-automation-wdjs4i/tools/capture-engine/install.sh)
```

- "명령어 라인 도구를 설치하시겠습니까?" 창이 뜨면 **설치**를 누르고, 끝나면 위 한 줄을 다시 붙여 넣습니다.
- Node 가 없다고 하며 nodejs.org 가 열리면 **LTS** 를 받아 설치한 뒤 위 한 줄을 다시 붙여 넣습니다.

끝나면 바탕화면에 **웹사이트 스냅샷.command** 가 생깁니다.

## 매번
바탕화면의 **웹사이트 스냅샷.command** 를 더블클릭합니다. 최신 코드를 자동으로 받고 앱이 브라우저에 열립니다.
그 터미널 창은 닫지 말고 두세요. 끌 때는 그 창에서 `Ctrl+C`.

처음 더블클릭할 때 "확인되지 않은 개발자" 경고가 뜨면, 파일을 **오른쪽 클릭 → 열기**로 한 번 열어 주면 그 뒤로는 바로 열립니다.

## 쓰는 법
1. 주소를 넣고 **분석하기** → 메뉴구조가 나옵니다. 찍을 페이지를 체크합니다(깊이로 한 번에 고를 수 있습니다).
2. 화면 크기(1440 / 1920 / 375)를 고르고 **캡처 시작**.
3. 카드에서 결과를 보고, 체크한 것만 **출력하기**(IMG 폴더 또는 PDF 한 권). 저장 위치는 맥의 저장 창에서 정합니다.
4. 자동으로 잘 안 찍히는 페이지는 카드의 **직접 찍기** → 크롬 창 오른쪽 아래 버튼으로 화면을 하나씩 찍고 **완성**.

## 문제가 생기면
- 앱 주소가 안 열리면: 실행 파일을 더블클릭한 터미널 창이 열려 있는지 확인합니다.
- 메뉴가 안 잡히면: 2단계의 "메뉴를 찾지 못했어요 — 진단" 내용을 캡처해 담당자에게 보냅니다.
